# ti-sn76489

The Texas Instruments SN76489 programmable sound generator.

| Crate | Registry |
|---|---|
| [`emu198x-ti-sn76489`](crates/emu198x-ti-sn76489) | [crates.io](https://crates.io/crates/emu198x-ti-sn76489) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the BBC Micro, ColecoVision, Memotech MTX, Sega Master System, SG-1000 and Mega Drive, and Sord M5.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
